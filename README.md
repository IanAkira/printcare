# PrintCare — aplicativo (MVP)

Protótipo do PrintCare, sistema de manutenção preventiva de impressoras desenvolvido para a A3 da Unisul (Equipe 1).

**Abrir o aplicativo:** https://ianakira.github.io/printcare/

Os dados exibidos são fictícios (Universidade Horizonte, caso EcoCampus). O aplicativo roda inteiro no navegador; nada é enviado para servidores.
